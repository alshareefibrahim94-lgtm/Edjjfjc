# أخبار السعودية 🇸🇦

تطبيق ويب للهاتف (PWA) يجمع أخبار المملكة من مصادر متعددة في **ودجات** قابلة للتخصيص، بواجهة عربية كاملة.

## المزايا

- ودجت مستقل لكل مصدر: واس، سبق، عكاظ، الرياض، العربية، الشرق الأوسط، الجزيرة، الاقتصادية، أرقام، أخبار 24، عاجل، المدينة، الوطن، اليوم، مكة، الإخبارية، الرياضية (ومصدران بالإنجليزية اختياريان).
- ودجت «آخر الأخبار» وشريط «أبرز الأخبار» بالصور.
- ودجت «اهتماماتي»: أضف كلمات مفتاحية لتتابع مواضيعك.
- تبويب «فيديو»: أحدث مقاطع قنوات المصادر على يوتيوب (القنوات في `public/videos.json`) تُشاهد داخل التطبيق وتُشارك.
- متوافق مع الهواتف القابلة للطي: عمود واحد على الشاشة الخارجية، وعمودان ونافذة عرض وسطية على الشاشة الداخلية.
- قسم «الاتحاد» بألوان النادي (أصفر وأسود): أخبار نادي الاتحاد، الصفقات والشائعات، المقاطع، وروابط تفتح حسابات النادي ووسومه في تطبيقات إكس وتيك توك ويوتيوب.
- قسم «الألعاب» (بنفسجي): أخبار الألعاب بالعربية والإنجليزية من IGN وGameSpot وEurogamer وغيرها (`public/gaming.json`) ومقاطع قنوات الألعاب. القسمان في تبويب «أقسامي».
- تصنيفات: محليات، سياسة، اقتصاد، رياضة، تقنية، ثقافة.
- بحث عربي ذكي (يتجاهل التشكيل والهمزات)، حفظ الأخبار، مشاركة، تمييز المقروء والجديد.
- تخصيص: اختيار المصادر وترتيبها، عدد الأخبار في الودجت، حجم الخط، الوضع الداكن، إخفاء الصور.
- التاريخ الهجري (أم القرى) والميلادي، ويعمل بدون إنترنت على آخر نسخة محمّلة.

## كيف يعمل

`.github/workflows/news.yml` يعمل كل ٢٠ دقيقة تقريباً: يجلب خلاصات RSS للمصادر في `public/sources.json`
(مع بديل تلقائي عبر أخبار Google/Bing إذا تعطّلت خلاصة المصدر)، يكتب `public/data/news.json`، ثم ينشر مجلد `public/` على GitHub Pages.

## التشغيل لأول مرة

1. من إعدادات المستودع: **Settings → Pages → Source = GitHub Actions**.
2. شغّل سير العمل من تبويب **Actions** (أو انتظر التشغيل المجدول).
3. افتح `https://<المستخدم>.github.io/<المستودع>/` على الهاتف ثم «إضافة إلى الشاشة الرئيسية».

## تطبيق أندرويد (APK)

مجلد `android/` يغلّف الواجهة نفسها في تطبيق أندرويد خاص:

- الهاتف يجلب الأخبار مباشرةً من المصادر عند فتح التطبيق، دون المرور بـ GitHub.
- **وضع القراءة**: الضغط على الخبر يعرض العنوان والصورة والنص فقط داخل التطبيق، بلا إعلانات أو نوافذ منبثقة.
- `.github/workflows/android.yml` يبني الملف وينشره في: `releases/download/app/saudi-news.apk`.

## محلياً

```bash
npm test          # اختبارات محلّل الخلاصات
npm run fetch     # جلب الأخبار إلى public/data/news.json
npm run serve     # http://localhost:8080
```

لإضافة مصدر: أضف عنصراً إلى `public/sources.json` (المعرّف، الاسم، اللون، النطاق، روابط RSS).
